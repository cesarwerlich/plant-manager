# 🌿 Branding & Identidade Visual — Versão 1 (Arquivada para Referência)

> **Nota:** Esta é a proposta conceitual v1 inicial. Uma nova iteração (v2) será criada pelo Claude Code / equipe para explorar novos caminhos de branding, nomes e identidades visuais.

---

## 1. Conceito Original v1
* **Nome Proposto:** Dr. Garden (com assistente "Dra. Flora")
* **Posicionamento:** "Médico das plantas" focado em diagnóstico de folhas e saúde botânica.
* **Problema identificado no feedback:** O visual e posicionamento ficaram excessivamente clínicos / literais com a cruz médica, sem a leveza e estética moderna desejadas para um app de jardinagem contemporâneo.

## 4. Próximos Passos para a v2 (Sugestões para o Claude / Designer)
1. **Desvincular do estigma hospitalar/médico:** Evitar cruzes vermelhas/médicas literais que lembram farmácia ou hospital.
2. **Explorar nomes alternativos:**
   - *VerdeLab* / *Verdant*
   - *SproutIQ* / *Botanik*
   - *FloraGuia* / *Jardim Vivo*
   - *Folha.ai* / *Plantae*
3. **Estilos de Design para v2:**
   - **Caminho 1 - Minimalista Japonês / Wabi-sabi:** Tons terrosos suaves (areia, oliva desbotada, cerâmica matcha), tipografia limpa, ilustrações finas botânicas.
   - **Caminho 2 - Tech Pop / App Moderno:** Gradientes vibrantes de verde-limão e menta fluorescente sobre fundo dark mode profundo (estilo apps Apple Design Award / Linear / Duolingo).
   - **Caminho 3 - Herbário Editorial / Lifestyle de Luxo:** Tipografia editorial clássica (estilo revista Kinfolk / Architectural Digest), fotografia autêntica e verde musgo profundo.
